# 因果迷宫 Demo 0：因果连锁验证版

这是《因果迷宫》的第一个极小可玩 Demo。

它不是完整游戏，只验证一个核心问题：

> 玩家能不能通过“攻击推人 → 撞墙伤害 → 死亡爆炸”打出一次因果连锁爽点。

## 玩法目标

- 4×4 小棋盘
- 玩家每回合可以移动或攻击
- 攻击相邻敌人会把敌人向攻击方向推 1 格
- 如果敌人被推到墙上，会受到额外撞墙伤害
- 敌人死亡时会爆炸，对周围 8 格敌人造成伤害
- 击败所有敌人即胜利

## 运行方式

不需要安装任何依赖。

直接用浏览器打开：

```text
causal-maze-demo/index.html
```

或者使用 VS Code 的 Live Server 插件打开本目录。

## 操作方式

- 点击玩家上下左右相邻空格：移动
- 点击玩家上下左右相邻敌人：攻击
- 点击“重开 Demo”：重置局面

## 初始局面

```text
[ ][ ][ ][ ]
[ ][P][E][W]
[ ][ ][E][ ]
[ ][ ][ ][ ]
```

第一次点击玩家右侧敌人，就能看到核心连锁：

```text
玩家攻击
↓
敌人被推向墙
↓
撞墙受到额外伤害
↓
敌人死亡爆炸
↓
爆炸伤害击杀旁边敌人
↓
胜利
```
