# AI 投资复盘与风险报告助手

本项目面向个人投资者、小资金账户、小型投研团队和业余量化用户，核心目标是把持仓、基金、ETF、股票、净值曲线和交易记录整理成看得懂、可追溯、能复盘、能控制风险的分析报告。

它不是机构级 Bloomberg / Wind / FactSet 终端，也不是自动交易系统。系统不提供直接买入/卖出指令，不承诺 AI 自动赚钱，不接入实盘下单。

## 核心能力

- 上传持仓、净值或交易记录，生成投资复盘报告
- 整理过去表现、近期变化、回撤、波动和集中度
- 检查小资金账户是否单一持仓过重、交易过频或风险承受不足
- 输出下一步观察清单，例如复核数据、观察回撤、补充交易流水
- 导出 Markdown、PDF、Word 报告
- 保留历史复盘记录，方便周度或月度对比

## 报告类型

- 个人持仓体检报告
- 基金/ETF 分析报告
- 小资金组合风险报告
- 交易复盘报告
- 亏损原因分析报告
- 定投/补仓观察报告
- 每周账户复盘报告

## 报告口径

系统统一使用谨慎复盘口径：

- 可以说：观察、复核、验证、预警、补充数据、进入下一轮研究
- 不说：建议买入、建议卖出、强烈推荐、稳赚、AI 判断会上涨

报告结论会尽量说明数据来源和可信度。若缺少成本价、买入日期、分红、手续费或完整交易流水，报告会降低结论置信度。

## 快速开始

```bash
python -m pip install -r requirements.txt
python web_app.py
```

访问：

```text
http://127.0.0.1:5001
```

推荐主入口：

```text
上传持仓 / 净值 / 交易记录，生成投资复盘报告
```

## 常用数据字段

最小可用字段：

- `date`
- `nav` / `close` / `return`

持仓体检建议补充：

- `symbol`
- `quantity`
- `avg_cost`
- `weight`

交易复盘建议补充：

- `pnl`
- 买入日期
- 卖出日期
- 手续费
- 分红
